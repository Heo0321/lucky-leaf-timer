# 🍀 Lucky Leaf Timer

심플하고 예쁜 파스텔 브라운 테마의 포모도로(Pomodoro) 타이머 Android 앱입니다.

## 웹사이트

- 소개 페이지: https://Heo0321.github.io/lucky-leaf-timer/
- 개인정보처리방침: https://Heo0321.github.io/lucky-leaf-timer/privacy-policy.html

## 주요 기능

- 포모도로 타이머 (집중/휴식 사이클)
- 통계 탭 (일별/누적 집중 시간)
- 설정 탭 (타이머 길이, 알림 등)
- Google AdMob Native Ads 배너 광고
- Google Play Billing을 통한 광고 제거 인앱 상품 (2,900원)
- Google Play In-App Review 연동

## 사용하지 않는 기능

- Firebase
- 로그인 / 회원가입
- 자체 서버
- 위치, 연락처, 카메라, 마이크, 사진, 파일 접근 권한

## 개발 환경

| 항목 | 내용 |
|---|---|
| 언어 | Kotlin |
| UI | Jetpack Compose |
| 최소 SDK | API 21 (Android 5.0) |
| 광고 SDK | Google Mobile Ads (AdMob) |
| 결제 | Google Play Billing Library |
| 개인정보 동의 | Google UMP SDK |
