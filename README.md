# 🍀 Lucky Leaf Timer

심플하고 예쁜 파스텔 브라운 테마의 포모도로(Pomodoro) 타이머 Android 앱입니다.

## 웹사이트

- 소개 페이지: https://Heo0321.github.io/lucky-leaf-timer/
- 개인정보처리방침: https://Heo0321.github.io/lucky-leaf-timer/privacy-policy.html

## 주요 기능

- **포모도로 타이머**: 집중/휴식 사이클 자동 반복
- **클라우드 백업 및 복원**: 이메일 계정 연결로 기기 변경 시 기록 이어보기
- **소셜 챌린지**: 초대 코드로 친구와 그룹 생성 및 실시간 집중 상태 공유
- **연령대별 통계 비교**: 동일 연령대 평균과 나의 집중력 비교
- **스마트 히트맵 달력**: 집중도 시각화 및 월별 상세 분석
- **종료 시각 예약**: 원하는 시각에 타이머 자동 정지
- **알림 방식 선택**: 소리/진동/무음 모드 중 선택
- **광고 제거 인앱 상품**: 2,900원으로 광고 제거 가능
